# SEKIYA.so 入居確定フォーム（LINEミニアプリ）

入居が決まった人にLINEの中で開いてもらう入力フォーム。Googleフォームの置き換え。

- 画面: `index.html` / `app.js` / `style.css` / `i18n.js`（日本語が基本。切替は 日本語→英語→中国語（簡体字）→韓国語 の順）
- 設定: `config.js`（LIFF ID と Apps Script の URL。どちらも公開してよい値）
- 受け口: `gas/Code.gs`（Google Apps Script。スプレッドシート「入居者顧客情報」→ シート「SEKIYA.so入居確定フォーム」に1行追加し、寺本のLINEに通知）

## 流れ

```
入居者のLINE ──開く──> ミニアプリ（GitHub Pages）
                         │ 送信（LINEのIDトークン付き）
                         ▼
                 Apps Script Web アプリ ──IDトークンをLINEに照合
                         │
           ┌─────────────┴─────────────┐
           ▼                           ▼
 スプレッドシートに1行追加        寺本のLINEにプッシュ通知
 （見出し名で列を合わせる。      （氏名・国籍/在留資格・入居期間・
  新しい項目は右端に自動で列追加）  在留期限の要確認・行へのリンク）
```

## 入力の分岐

| 国籍 | 聞くこと |
|---|---|
| 日本国籍 | マイナンバーカードの有無（番号は聞かない）＋本人確認書類を提示する旨の確認 |
| 日本以外 | 国名・在留資格・在留カード番号・在留期間の満了日＋在留カード提示の確認 |
| 日本以外で「短期滞在」 | 在留カードは無いので番号・満了日は聞かず、パスポート提示の案内 |

- 職業が「学生」のときだけ学年を聞く
- 送信前に確認画面。各ブロックの「修正」から戻れる
- 在留期間の満了日が退去予定日より前なら、確認画面で注意を出し、シートの「要確認」列と通知に載せる
- 入力途中の内容は端末に一時保存（在留カード番号はブラウザを閉じると消える）

## 初回セットアップ

### 1. Apps Script（受け口）
1. スプレッドシート「入居者顧客情報」を開く → 拡張機能 → Apps Script
2. `gas/Code.gs` の中身を貼り付けて保存
3. プロジェクトの設定 → スクリプト プロパティに3つ追加
   - `LIFF_CHANNEL_ID` … 手順2で作るチャネルのチャネルID
   - `NOTIFY_LINE_TOKEN` … 寺本個人の通知用チャネルのチャネルアクセストークン
   - `NOTIFY_USER_ID` … 同じ通知用チャネルの「チャネル基本設定」にある「あなたのユーザーID」
   - ⚠ SEKIYA.so公式アカウントのトークンは入れない（通知が入居者に届く事故を防ぐため、通知は寺本個人チャネルからの個別送信にしている）
4. エディタで `testNotify` を実行 → 寺本のLINEにテスト通知が届けばOK（初回は権限の許可を求められる）
5. デプロイ → 新しいデプロイ → 種類「ウェブアプリ」／実行ユーザー「自分」／アクセスできるユーザー「全員」
6. 表示された URL（`https://script.google.com/macros/s/…/exec`）を `config.js` の `GAS_URL` に入れる

### 2. LINE（ミニアプリ）
1. LINE Developers コンソール → SEKIYA.so公式アカウントがあるプロバイダー → 新規チャネル「LINEミニアプリ」（未認証のままでも使える）
2. エンドポイントURL に GitHub Pages の URL（手順3）を設定
3. スコープ: `openid`・`profile`・`chat_message.write` をオン
4. 発行された LIFF ID を `config.js` の `LIFF_ID` に、チャネルIDを Apps Script の `LIFF_CHANNEL_ID` に入れる
5. ミニアプリのURLを公式アカウントのリッチメニューやトークで入居者に送る

### 3. 公開（GitHub Pages）
- このリポジトリの Settings → Pages → Branch: `main` / root
- 動作確認だけなら `?dev=1` を付けるとLINE外で開け、送信はされない

### 4. 切り替え
- ミニアプリで1件テスト送信 → シートに行が増え、寺本のLINEに通知が来るのを確認
- Googleフォーム「SEKIYA.so入居確定フォーム」の回答受付をオフにする（過去の回答はシートにそのまま残る）

## クラウドサイン連携（契約締結 → 入居者LINE通知）

1. Apps Scriptのスクリプトプロパティに追加:
   - `SEKIYA_LINE_TOKEN` … SEKIYA.so公式アカウントのチャネルアクセストークン（入居者への通知用）
     - ⚠ 運営通知に使う `NOTIFY_LINE_TOKEN`（個人チャネル）とは別物
2. Apps Script Web アプリの URL（`https://script.google.com/.../exec`）をクラウドサインのWebhook URLに設定
   - クラウドサイン管理画面 → Webhook → 「書類の完了（document.completed）」を選択
3. 動作: 全員が署名完了 → クラウドサインがGASにPOST → シートの「手続き状況」を「契約締結」に更新 → 入居者のLINEに通知

## 申請フェーズの確認（入居者向け）

ミニアプリのトップ画面・送信完了画面に「申請状況を確認する」ボタンがあります。
タップすると自分の申請フェーズをタイムラインで確認できます。

フェーズ: 受付 → 審査中 → 契約書送付 → 契約締結 → 入居確認 → 入居完了

「手続き状況」列をシートで直接書き換えると、次回確認時に反映されます。

## シートに追加される列
既存の列（タイムスタンプ〜退去までに達成したいこと）はそのまま使い、無い列は初回送信時に右端へ自動で足す:
`国籍区分` `国籍` `マイナンバーカード` `在留資格` `在留資格（その他）` `在留カード番号` `在留期間の満了日` `本人確認書類の提示` `回答言語` `要確認` `LINE表示名` `LINE userId` `手続き状況`

`手続き状況` は「受付」で入る。今後、ここを変えたら入居者本人のLINEに知らせる仕組みを足せる（`LINE userId` を保存しているため）。
